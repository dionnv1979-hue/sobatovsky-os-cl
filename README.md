# SOBATOVSKY OS

Персональная система продуктивности для iPhone: задачи, база знаний, карточки с интервальным повторением, таймер фокуса, XP/уровни/достижения, цели и привычки, аналитика, резервные копии JSON. SwiftUI, iOS 17+, без интернета и сторонних библиотек. Интерфейс на русском.

**Статус:** исходный код написан без доступа к macOS/Xcode, поэтому в момент выдачи проект **не компилировался и не запускался**. Первая реальная проверка — сборка в GitHub Actions. См. `ИНСТРУКЦИЯ-GITHUB.md`.

## Структура
* `project.yml` — описание проекта для XcodeGen (Xcode-проект генерируется командой `xcodegen generate`).
* `.github/workflows/build-ipa.yml` — сборка Release без подписи на macOS и упаковка IPA. Копия: `WORKFLOW-BACKUP.txt`.
* `scripts/package_ipa.sh` — кладёт `.app` в `Payload/`, архивирует в IPA и проверяет содержимое (Info.plist, исполняемый файл arm64, Assets.car, отсутствие .swift).
* `tools/make_icon.py` — генератор иконки (Pillow).
* `SOBATOVSKY-OS/` — исходники: `App`, `DesignSystem`, `Models`, `Persistence`, `Services`, `Features/*`, `Resources`.
* `SOBATOVSKY-OSTests/` — модульные тесты логики (XP-уровни, интервалы повторения, серии, бэкап).

## Сборка вручную на Mac
```
brew install xcodegen
xcodegen generate
open SOBATOVSKY-OS.xcodeproj
```
Для IPA без подписи:
```
xcodebuild -project SOBATOVSKY-OS.xcodeproj -scheme SOBATOVSKY-OS -configuration Release -sdk iphoneos -destination 'generic/platform=iOS' -derivedDataPath build CODE_SIGNING_ALLOWED=NO CODE_SIGNING_REQUIRED=NO CODE_SIGN_IDENTITY="" build
bash scripts/package_ipa.sh   # результат: output/SOBATOVSKY-OS.ipa
```

## Ключевые решения
* **Хранение:** один JSON-файл (Application Support), атомарная запись, схема версии 1, устойчивое чтение (повреждённый файл сохраняется отдельно). SwiftData не используется, чтобы не зависеть от нюансов миграций.
* **XP:** журнал событий с уникальными ключами (`task:<id>`, `focus:<id>`…). Награда начисляется один раз; при отмене выполнения задачи XP возвращается. Кривая уровней: начало уровня n = 25·(n−1)·(n+2) XP. Баланс — `Services/XPService.swift`.
* **Серия:** день активен, если завершена задача или сессия фокуса либо повторена карточка. Открытие приложения серию не увеличивает.
* **Таймер:** хранит время окончания и считает остаток по системным часам; переживает блокировку, сворачивание и перезапуск. Раньше времени завершённая сессия сохраняется как незавершённая и XP не даёт (минуты учитываются, если прошло ≥ 5 минут).
* **Повторение карточек:** упрощённый SM-2 (Не помню / Сложно / Помню / Легко), интервалы сохраняются.
* **Уведомления:** локальные; разрешение запрашивается при включении соответствующей функции.

## Известные ограничения
* Не проверялось на реальном устройстве и симуляторе (в среде разработки не было macOS).
* Заметки — обычный текст без форматирования.
* Звук окончания фокуса играет, пока приложение открыто; в фоне — звук системного уведомления.
* Размеры шрифтов фиксированные (по ТЗ), поэтому Dynamic Type поддержан частично.
* Повторяющиеся задачи создают следующую задачу при выполнении текущей.

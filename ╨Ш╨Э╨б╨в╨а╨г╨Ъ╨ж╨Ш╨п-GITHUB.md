# Как получить SOBATOVSKY-OS.ipa через GitHub (для новичка)

Нужен компьютер (Windows или Mac) и браузер. Телефона недостаточно: на сайте GitHub с телефона нельзя загрузить папки.
Mac и Xcode не нужны: сборку выполнит бесплатный сервер GitHub.

## 1. Аккаунт
1. Открой https://github.com → **Sign up**, создай аккаунт, подтверди почту.

## 2. Подготовь файлы
1. Распакуй `SOBATOVSKY-OS-Source.zip` (правая кнопка → «Извлечь всё» / двойной клик на Mac).
2. Включи показ скрытых файлов — внутри есть папка `.github`, её нельзя потерять:
   * Windows: Проводник → вкладка **Вид** → галочка **Скрытые элементы**.
   * Mac: в Finder нажми **Cmd + Shift + .** (точка).
3. Открой распакованную папку. Внутри должны быть: `.github`, `Config`, `SOBATOVSKY-OS`, `SOBATOVSKY-OSTests`, `scripts`, `tools`, `project.yml` и др.

## 3. Создай репозиторий
1. На github.com нажми **+** (справа вверху) → **New repository**.
2. Repository name: `sobatovsky-os`.
3. Выбери **Public** (сборки бесплатны и не ограничены; в проекте нет ключей и секретов). Private тоже работает, но сборка на macOS тратит бесплатный лимит минут быстрее.
4. Галочки «Add a README / .gitignore / license» **не ставь**. Нажми **Create repository**.

## 4. Загрузи проект
1. На странице пустого репозитория нажми ссылку **uploading an existing file**.
2. Открой папку проекта, выдели **всё её содержимое** (Ctrl+A / Cmd+A) и перетащи в окно браузера. Перетаскивай именно содержимое, а не саму внешнюю папку.
3. Дождись окончания загрузки (всего около 40 файлов; лимит GitHub — 100 файлов за раз).
4. Внизу нажми зелёную **Commit changes**.

## 5. Проверь, что workflow на месте
1. В репозитории открой папки `.github` → `workflows`: там должен лежать `build-ipa.yml`.
2. Если папки `.github` нет (браузер её не загрузил): **Add file → Create new file**, в поле имени введи
   `.github/workflows/build-ipa.yml` (слэши создадут папки), открой файл `WORKFLOW-BACKUP.txt` из архива, скопируй всё содержимое в большое поле и нажми **Commit changes**.

## 6. Запусти сборку
Сборка стартует сама после загрузки. Чтобы запустить вручную:
1. Вкладка **Actions** (если просит — нажми «I understand my workflows, go ahead and enable them»).
2. Слева выбери **Build IPA** → справа **Run workflow** → зелёная **Run workflow**.
3. Нажми на появившийся запуск. Жёлтый кружок — идёт сборка (обычно 8–15 минут). Зелёная галочка — готово.

## 7. Скачай IPA
1. Открой завершённый зелёный запуск и прокрути страницу вниз до блока **Artifacts**.
2. Нажми **SOBATOVSKY-OS-IPA** — скачается ZIP.
3. Распакуй его: внутри `SOBATOVSKY-OS.ipa` и `IPA-CHECK.txt` (отчёт проверки: что внутри именно собранное приложение, архитектура arm64, Bundle ID и т.д.).
4. Артефакт хранится 30 дней.

## Если сборка красная (✗)
1. Открой запуск → нажми на красный шаг (например, «Build Release…») и скопируй последние ~50 строк лога.
2. Либо скачай артефакт **build-log** на странице запуска.
3. Пришли это мне — я исправлю код. Проект писался без возможности скомпилировать его на macOS, поэтому ошибки при первой сборке возможны и это нормально.
4. Заменить исправленный файл: в репозитории открой файл → значок карандаша → вставь новый текст → Commit changes. Сборка стартует заново.
(Отдельная задача «Unit tests» может быть красной — на выдачу IPA она не влияет.)

## Подпись и установка IPA
IPA собран **без подписи** (`CODE_SIGNING_ALLOWED=NO`) — его нельзя установить напрямую. Подпиши своим сертификатом, например:
* **Sideloadly** (Windows/Mac) — войти своим Apple ID и установить по USB. С бесплатным аккаунтом срок жизни 7 дней.
* **AltStore / SideStore**, **TrollStore**-совместимые инструменты, **zsign / codesign / fastlane resign** — если у тебя платный сертификат и профиль.

Что учесть:
* Bundle ID в проекте `com.sobatovsky.productivity`. Профиль должен соответствовать ему, либо подписывающий инструмент должен переписать Bundle ID.
* Приложению не нужны особые разрешения (entitlements): только локальные уведомления. Push-уведомления и iCloud не используются.
* Минимальная версия iOS — 17.0.
* Ограничения подписи зависят от типа аккаунта Apple (бесплатный: 7 дней и лимит приложений; платный: год). Это правила Apple, а не приложения.
